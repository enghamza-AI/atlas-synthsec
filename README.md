> *A branded search ad can show a spectacular ROAS while creating almost no real business impact — because it mostly reaches people already searching for you by name.*

## What is this

Atlas is a synthetic-data demo of [SynthSec's](#author) marketing intelligence methodology: it separates **naive ROAS** (what a standard last-click dashboard reports) from **true incremental impact** (what a randomized holdout test actually measures), and uses the campaigns that WERE properly tested to estimate impact for the campaigns that weren't.

This is a portfolio piece, not a client deliverable. All data is synthetic and clearly labeled as such.

**[Try it on streamlit →](https://atlas-synthsec.streamlit.app)**

## The problem

Last-click attribution credits a campaign for every conversion that happened after someone saw it — including people who would have converted anyway. Channels that target people who already intend to buy (branded search, retargeting) look spectacular on naive metrics and often create the least real incremental value, while channels reaching cold audiences (social, out-of-home) can look mediocre naively while actually driving most of their conversions. Naive metrics alone can't tell these apart — only a controlled experiment (a holdout group that never sees the ad) can.

## What it does

```
synthetic campaign + weekly-performance CSVs
        │
        ▼
  pandas cleaning                → validate both tables, reconcile weekly rows to campaigns
        │
        ▼
  feature engineering            → naive ROAS (everyone) + true incremental ROAS (holdout-tested campaigns only)
        │
        ▼
  K-Means segmentation           → scale / sustain / cut / audit (unsupervised + naive-vs-true gap override)
        │
        ▼
  incremental-impact model       → RandomForestRegressor estimates true ROAS for untested campaigns (supervised)
        │
        ▼
  recommended actions            → plain-English next step + urgency, labeled measured vs. estimated
        │
        ▼
  Streamlit dashboard            → deployed on Hugging Face Spaces
```

## Key concepts

| Concept |
|---|---|
| Randomized holdout test | A portion of a campaign's audience deliberately not shown the ad, to measure what would have happened anyway |
| Naive vs. incremental ROAS | Two different numbers for the same campaign — last-click ROAS vs. ROAS attributable only to people the ad actually changed |
| Train-on-tested, score-everyone | A regression model learns the naive-to-incremental relationship from the ~30% of campaigns with a real holdout test, then estimates it for the rest |
| Measured vs. estimated labeling | Every impact score is explicitly tagged with its confidence level — never silently blended |
| "Audit" segment | A business override flagging campaigns where naive and true metrics disagree sharply, regardless of overall performance tier |

## Dataset

100% synthetic, generated by `src/synthetic_data.py`. Each campaign has a hidden channel-level organic propensity (how likely its audience was to convert anyway) and true lift (the ad's actual causal effect) — for holdout-tested campaigns, these are recovered via a simulated randomized experiment, not read off a leaked column.
